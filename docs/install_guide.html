🔧 설치

터미널 AI에 나무 붙이기

Claude Code나 agy를 쓰신다면 이 문서 하나면 됩니다. 설치부터 첫 작업, 업데이트와 삭제까지 순서대로 담았습니다.

브라우저에서 AI를 쓰신다면 이 문서가 아닙니다. 설치가 아니라 주소를 붙이는 방식이라 절차가 완전히 다릅니다 → 나무 클라우드(가장 쉬움) 또는 직접 서버 돌리기. 두 방법의 차이는 안내서 10장에 있습니다.

차례

  1. 준비물
  2. Claude Code에 설치하기
  3. agy에 설치하기
  4. 개발형 — 나무 자체를 고칠 때
  5. 잘 설치됐는지 확인하기

  9. 삭제
  10. 막혔을 때

1. 준비물

  • Claude Code 또는 agy — 둘 중 하나가 이미 설치돼 있어야 합니다. 둘 다 있으면 양쪽에 설치해도 됩니다(기억은 하나로 합쳐집니다).
  • Python 3.12 이상
  • 인터넷 연결 — 설치할 때 나무를 내려받습니다.

GitHub 계정은 필요 없습니다. 나무 저장소가 공개라 그냥 내려받아집니다. (뒤의 7장 여러 PC 동기화를 켤 때만 계정이 필요합니다.)

2. Claude Code에 설치하기

터미널에 아래 두 줄을 차례로 칩니다.

claude plugin marketplace add onmiso-hash/namu-agent
claude plugin install namu@namu-marketplace

끝입니다. Claude Code 대화창 안에서 하고 싶다면 첫 줄 대신 /plugin marketplace add onmiso-hash/namu-agent를 쳐도 똑같이 됩니다.

설치가 끝나면 Claude Code를 한 번 껐다 켜십시오. 그래야 반영됩니다.

화면 아래 한 줄 켜기

지금 어떤 작업이 열려 있는지, 나무 버전이 몇인지를 화면 맨 아래에 항상 보여주는 기능이 있습니다. 대화창에 이렇게 치면 자동으로 붙습니다.

/namu:statusline-setup

이 줄에는 [나무 버전] [모델] 폴더 | 📌 진행 중인 작업 | 남은 여유가 표시됩니다. 연결한 뒤에는 Claude Code를 다시 시작해야 보입니다.

이미 다른 하단 표시를 쓰고 계시면 나무가 덮어쓰지 않고 멈춰 기존 설정을 보여줍니다. 바꾸고 싶으실 때만 다시 진행하시면 됩니다.

3. agy에 설치하기

agy plugin install https://github.com/onmiso-hash/namu-agent.git

하단 한 줄은 Claude Code와 같은 방법(/namu:statusline-setup)으로 켭니다. 나무가 어느 쪽에 설치돼 있는지 알아서 찾아 붙입니다.

agy에서 알아둘 것 — agy는 다시 설치할 때 기존 파일을 지우지 않고 덮어씁니다. 그래서 예전 파일이 남아 이상하게 동작할 수 있습니다. 다시 깔 때는 지우고 나서 깔아야 깨끗합니다. 아래 8장 업데이트의 /namu:update를 쓰면 이 순서를 알아서 지켜 줍니다.

또 하나 — 다시 설치한 직후 첫 대화에서는 나무가 아직 안 보일 수 있습니다. 경로를 바로잡는 과정이 한 번 돌아야 하기 때문입니다. 대화를 한 번 닫았다 열면 됩니다.

4. 개발형 — 나무 자체를 고칠 때

나무의 코드를 직접 고쳐 보고 싶다면, 저장소를 통째로 내려받아 그것을 설치원으로 지정합니다.

git clone https://github.com/onmiso-hash/namu-agent.git
claude plugin marketplace add /내려받은/경로/namu-plugin
claude plugin install namu@namu-marketplace

이렇게 하면 코드를 고치는 즉시 반영됩니다. 다시 설치할 필요 없이 Claude Code만 껐다 켜면 됩니다.

개발용으로 처음 내려받았다면 아래도 한 번 실행해 두십시오. 버전을 잘못 올리는 실수를 미리 막아 줍니다.

sh scripts/setup_dev_hooks.sh

헷갈리기 쉬운 지점 — 위 2장(인터넷에서 설치)과 이 4장(내 폴더에서 설치)은 이름이 같습니다(namu-marketplace). 그래서 개발용으로 쓰던 PC에서 실수로 2장 명령을 치면, 내 폴더를 보던 설정이 조용히 인터넷 쪽으로 바뀝니다. 그 뒤로는 코드를 고쳐도 반영되지 않습니다 — 다시 4장 명령으로 되돌리면 됩니다.

5. 잘 설치됐는지 확인하기

첫 대화가 조용한 것은 정상입니다. 나무는 보여줄 기억이 있어야 브리핑을 띄웁니다. 방금 설치했다면 기억이 0건이라 아무것도 안 뜹니다. 설치 실패가 아닙니다.

두 가지로 확인하십시오.

  • 1

    대화창에 /mcp를 칩니다

    목록에 plugin:namu:namu-memory가 connected 상태로 보이면 기억 장치가 살아 있는 것입니다. 옆에 붙는 도구 개수는 버전에 따라 다릅니다.

  • 2

    AI에게 직접 물어봅니다

    "나무 기억에서 recall 해봐"라고 하십시오. 방금 설치했다면 "저장된 기억이 비어 있다"고 답합니다 — 이 대답이 곧 정상이라는 증거입니다. 도구를 부르는 것 자체가 안 되면 그때가 설치 문제입니다.

6. 첫 하루 — 실제로 써 보기

기억은 어디에 쌓이나요

전부 여러분 컴퓨터의 ~/.namu 폴더 한 곳에 쌓입니다. 어느 프로젝트에서 실행하든 이 경로는 바뀌지 않습니다.

무엇어디에언제 생기나
교훈·개인 사실·쪽지~/.namu/memory/처음 기록할 때
작업일지~/.namu/tasks/<프로젝트 폴더 이름>/작업을 처음 열 때
검색용 색인~/.namu/db/나무가 처음 켜질 때

작업일지가 프로젝트 폴더 안이 아니라 ~/.namu 아래에 생기는 것은 의도한 설계입니다. 공개 저장소에 개인 작업 기록이 딸려 올라가는 것을 막고, 프로젝트에 git이 없어도 PC 사이에서 공유되게 하기 위해서입니다.

첫 작업 돌려 보기

나무를 제대로 느껴 보려면 실제 작업 한 건을 /namu-task로 돌려 보는 것이 가장 좋습니다. 대화창에 이렇게 칩니다.

/namu-task

그러면 이 순서로 흘러갑니다.

  • 1

    작업 정하기

    AI가 목적과 완료 조건 초안을 내고, 여러분 확인을 받은 뒤 확정합니다.

  • 2

    코딩 맡기기

    일꾼 AI가 실제 수정을 합니다. 부르기 전에 한 번 더 여쭙니다.

  • 3

    검수

    검사 담당 AI가 통과/실패를 판정합니다. 실패해도 마음대로 다시 돌리지 않고 여러분께 묻습니다.

  • 4

    교훈 남기기

    다시 쓸 만한 배움이 있으면 이유와 함께 기억에 남깁니다.

  • 5

    마무리

    커밋처럼 되돌리기 어려운 일은 승인을 기다립니다.

이름이 안 잡히면 /를 누르고 목록에서 namu로 시작하는 항목을 찾으십시오.

브리핑은 다음 대화부터

기억이 쌓이면, 새로 여는 대화의 맨 앞에 지난 상황이 자동으로 뜹니다 — 붙여둔 쪽지, 열려 있는 작업, 최근 교훈입니다. 지금 대화에는 안 나타나고 다음 대화부터 보입니다.

7. 여러 PC에서 같은 기억 쓰기 (권장)

플러그인 설치 + 이 동기화가 터미널에서 나무를 쓰는 권장 구성입니다. 여기까지 켜 두시면 더 하실 일이 없습니다.

켜지 않고 그냥 두면 기억은 그 PC 안에만 쌓입니다. 디스크가 죽으면 같이 사라지고, PC 두 대를 쓰면 따로 쌓여 합쳐지지 않습니다.

이것을 없애려면 여러분의 비공개 저장소에 기억을 자동으로 올리고 내리게 하면 됩니다. 한 번만 켜면 그다음부터는 손댈 일이 없습니다.

  • 1

    비공개 저장소를 하나 만듭니다

    GitHub에서 New repository → 이름은 자유(예: namu-memory) → Private을 고르고, 초기 파일 없이 빈 상태로 만듭니다.

    반드시 비공개여야 합니다. 교훈에는 여러분이 한 작업의 내용과 판단이 그대로 담기기 때문입니다. GitHub은 비공개 저장소도 무료입니다.

    직접 만들기 번거로우시면 나무 클라우드에 GitHub로 로그인해 보십시오 — 이름(namu-memory)과 비공개가 미리 채워진 생성 화면으로 안내해 주므로 버튼 한 번이면 만들어집니다.

  • 2

    그 PC에서 git 로그인을 해 둡니다

    gh auth login이 가장 간단합니다. 그 PC에서 이미 저장소에 올려 본 적이 있다면 대개 이미 되어 있습니다.

  • 3

    AI에게 한마디 합니다

    "namu_sync_setup을 <저장소 주소>로 실행해줘"라고 하면 끝입니다. 나머지 연결은 나무가 알아서 합니다.

켠 뒤에는 기억을 남길 때마다 자동으로 올라가고, 대화를 새로 열 때마다 다른 PC의 최신 기억을 자동으로 받아옵니다. 두 번째 PC는 같은 3번을 한 번 부르면 기존 기억을 잃지 않고 합쳐집니다.

완전 자동 백업은 아닙니다. 인터넷이 끊겼거나 git 로그인이 만료되면 조용히 로컬에만 쌓입니다 — 대화를 막지 않기 위해 일부러 그렇게 만들었습니다. 기록은 되는데 저장소에 안 보이면 ~/.namu/db/sync.log를 확인하십시오. 원인을 고치면 밀려 있던 것까지 한꺼번에 올라갑니다.

8. 업데이트

대화창에 이 한 줄이면 됩니다.

/namu:update

나무가 설치된 곳(Claude Code·agy)을 알아서 찾아 각각 맞는 방식으로 갱신하고, 화면 아래 한 줄도 새 경로로 다시 이어 줍니다. 설치 안 된 쪽은 건너뜁니다. 끝나면 해당 프로그램을 다시 시작해야 반영됩니다.

이 명령을 못 쓸 때

설치 방식Claude Codeagy
인터넷에서 설치(2장) claude plugin update namu@namu-marketplace
이름만 namu로 짧게 쓰면 "없다"고 나옵니다 — @namu-marketplace까지 꼭 붙이십시오.		 지우고 다시 설치합니다
Windows라면 namu-plugin/scripts/agy_reinstall.ps1이 이 순서를 대신 해 줍니다.
내 폴더에서 설치(4장) git pull 후 Claude Code 재시작.
다시 설치할 필요 없습니다.

업데이트 뒤 화면 아래 한 줄이 사라졌다면 — 설치 경로에 버전 번호가 들어 있어서, 버전이 오르면 예전 경로를 가리키게 됩니다. 에러도 없이 그냥 사라집니다. /namu:statusline-setup을 한 번 더 부르면 새 경로로 다시 이어집니다. (/namu:update를 쓰셨다면 이미 처리돼 있습니다.)

9. 삭제

Claude Code

claude plugin uninstall namu@namu-marketplace
claude plugin marketplace remove namu-marketplace

agy

agy plugin uninstall namu

지워도 기억은 남습니다. ~/.namu 폴더는 그대로라, 다시 설치하면 기억이 그대로 돌아옵니다. 기억까지 지우려면 그 폴더를 직접 지우셔야 합니다.

내 폴더에서 설치(4장)했던 경우, 위 명령 뒤에도 Claude Code 설정 파일에 그 폴더 경로가 남아 있으면 다시 시작할 때 되살아납니다. 그때는 설정에서 그 줄도 지우십시오.

10. 막혔을 때

설치했는데 /mcp 목록에 안 보입니다

프로그램을 껐다 켜셨는지 먼저 확인하십시오. 설치 직후에는 반영되지 않습니다. agy라면 재설치 직후 첫 대화에서 안 보일 수 있으니, 대화를 한 번 닫았다 여십시오.

화면 아래 한 줄이 안 보입니다

/namu:statusline-setup을 부르고 프로그램을 다시 시작하십시오. 업데이트 직후라면 경로가 옛 버전을 가리키고 있을 수 있는데, 같은 명령이 고쳐 줍니다.

코드를 고쳤는데 반영이 안 됩니다

내 폴더에서 설치(4장)한 상태여야 즉시 반영됩니다. 인터넷에서 설치(2장)한 상태라면 복사본이 돌아가고 있어서 /namu:update가 필요합니다. 실수로 2장 명령을 쳐서 설정이 바뀌었을 수도 있으니 4장의 경고 상자를 확인하십시오.

기억이 저장소에 안 올라갑니다

~/.namu/db/sync.log를 여십시오. 인터넷이나 git 로그인 문제라면 사유가 한 줄로 남아 있습니다. 고치면 밀려 있던 것까지 다음 기록 때 한꺼번에 올라갑니다.

일꾼 AI(코더·검수)를 다른 것으로 바꾸고 싶습니다

지금은 현재 쓰는 AI의 기본 일꾼만 동작합니다. 추가 설정도 추가 비용도 없습니다. 다른 엔진을 지정하는 자리는 마련돼 있지만 아직 동작하지 않으며, 지정하면 작업 절차가 알리고 멈춥니다.

일꾼이 쓰는 모델을 바꾸려면 일꾼 정의 파일(namu-plugin/cc-agents/)의 맨 위 model: 값을 고치십시오.
