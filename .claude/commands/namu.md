---
NAMU "세션 브리핑"을 출력한다. 아래 순서대로 수행하고 마지막에 정해진 형식으로만 보여줘라. 파일을 수정·생성하지 말 것(읽기 전용).

1. 최근 활동 (시간순, task 무관):
   ```bash
   python scripts/namu_journal.py --limit 8
   ```
   여러 task의 `log.md`를 시간순으로 합쳐 출력한다. 각 줄: `<날짜시각> <machine> <task slug> [태그] <내용>`.

2. 열린 task 목록:
   ```bash
   python scripts/namu_active_task.py --json
   ```
   JSON 배열이 나온다: `[{slug, title, last_ts, next}, ...]` (가장 최근 활동 순).
   `next`가 `null`이면 그 task는 "다음" 기록이 없는 것이다 — 조용히 빈칸으로 두지 말고 `(기록 없음)`이라고 명시하라.
   배열이 비어 있으면 "열린 task 없음"으로 간주한다.

3. `namu_recall`을 `limit=5`로 호출해 최근 교훈을 받는다.

4. 아래 형식으로만 출력(이 외 잡담 금지). 열린 task는 **전부** 센다 — 5개까지 보이고 나머지는 "… (N개 더)":

   🌳 NAMU 세션 브리핑

   🕘 최근 활동 (시간순, task 무관)
      <1단계 출력을 한 줄씩. 길면 줄여서>

   📂 열린 task <N>개
      ▸ <slug> · <제목>   최근 <MM-DD>   다음: <next 또는 (기록 없음)>
        <slug> · <제목>   최근 <MM-DD>   다음: ...

   💡 최근 교훈
      - <[outcome] task — reason>

   ▸는 가장 최근 활동한 task일 뿐 단정이 아닙니다. 어느 task를 이어갈지 말씀해 주세요.
   상세가 필요하면 "recall로 상세 보여줘"라고 하세요.

**금지** — 열린 task가 여럿인데 하나만 "진행 중"으로 단정하지 말 것. 무엇을 이어갈지는 사용자가 고른다.
"다음" 기록이 없는 task가 있으면 마지막에 한 줄로 알린다: 세션 끝에 `log.md`에 `[다음]` 태그 한 줄을 남기면 다음부터 표시된다고.
